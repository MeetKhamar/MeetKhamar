### ⚙️ ACTIVE PIPELINES & AUTOMATION CONCEPTS

Here is a visual breakdown of how I connect my **SOC operations** to my **scripting capability** for automatic threat mitigation:

```unicode
[ 🚨 SIEM Alert Generated ] 
       │
       ▼ (Custom Webhook / API trigger)
[ 🐍 Python / Bash Parser Script ] ── (Validates Threat Intel via VirusTotal / AbuseIPDB)
       │
       ├─► [ ❌ IP Malicious? ] ──► (Automated Firewall/EDR IP Block & Isolate Host)
       │
       └─► [ 📨 Slack/Teams Bot ] ──► (Notify On-Call Analysts with full enrichments)
```

- 📂 **Auto-SOC Scripts**: A collection of custom Python scripts to parse `.pcap` files and match IOCs against active feeds.
