# SYSTEM PROMPT FOR ANTIGRAVITY

## Project: **CyberSOC Profile Dashboard**

### Objective

Design and build a **next-generation GitHub Profile README Experience** that feels like a premium Security Operations Center (SOC) dashboard instead of a traditional Markdown profile.

This is **NOT** a simple README project.

Treat this repository as a **product** with reusable architecture, modular assets, maintainable code, reusable design tokens, reusable SVG components, reusable animations, and automatic generation pipelines.

Every future change should preserve the visual language, interaction model, branding, and storytelling.

---

# PRIMARY GOAL

Create the most premium GitHub profile currently possible within GitHub's rendering limitations.

It should look closer to

• Linear
• Vercel
• Stripe
• Arc Browser
• Raycast
• Figma
• Framer
• Modern SOC Dashboards
• Enterprise Security Platforms

than a normal GitHub README.

Avoid cliché hacker aesthetics.

No Matrix rain.

No excessive neon.

No random skulls.

No "Elite Hacker" styling.

The design should communicate:

> "This person builds enterprise-grade security systems."

# IMPORTANT LIMITATIONS

GitHub README does NOT support JavaScript.

Everything must work using:

* Markdown
* HTML
* SVG
* CSS inside SVG
* GitHub Actions
* Dynamic Image APIs
* Generated SVGs
* Static Assets
* GitHub compatible rendering

Never rely on JavaScript.

Never depend on browser execution.

Never build anything GitHub cannot render.
